# dotViewer 1.5.8 (15) — release verification

Released 2026-09-23 from tag `v1.5.8` (`ebbc213`, "chore(release): prepare 1.5.8"). `feat/usage-stats-and-updates` fast-forwarded onto
`main`, `feat/settings-window` rebased onto it and fast-forwarded; no PR.

## Changes

- Settings in their own window (dotViewer → Settings…, ⌘,): a native sidebar list of seven panes,
  System Settings-style grouped rows, and sidebar search that opens the pane and highlights the row.
  Markdown settings moved in; the main window's sidebar keeps Status and File Types plus a ⌘, link.
  The tab bar that lost clicks on an Intel Mac with macOS 15 (#31) is gone.
- Interface text size works (KI-020): text in the app's windows scales from 11 to 21 pt around 13;
  controls keep their size. Medium (same as the default) is now Default.
- The main window keeps its size across updates: the scene has a fixed id, and the per-build frame
  keys older versions left are removed at launch.
- `publish.sh` no longer needs `--build-number` on bash 3.2.
