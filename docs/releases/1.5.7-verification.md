# dotViewer 1.5.7 (14) — release verification

Released 2026-09-22 from tag `v1.5.7` (`0fb95aea7e1ceb6fa789aaf6e91bb99f9c22beac`). `feat/status-hero-logo` fast-forwarded onto `main`; no PR.

## Change

The Status page's `eye.fill` symbol is replaced by `AnimatedLogoView`, a SwiftUI port of the website hero (`site/components/logo-animated.tsx`): blob, ring and pupil drift toward the pointer by 6/12/22 pt with the site's spring constants, the blob turns every 90 s, the pupil breathes every 3.2 s, and the layers enter with the site's staggered springs. Tile and ring follow the app icon's light/dark variants. Reduce Motion keeps it still; the idle timeline pauses while the app is inactive.
