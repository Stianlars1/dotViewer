# dotViewer 1.5.5 (12) — release verification

Released 2026-09-14 from tag `v1.5.5` (`590c9d9acbe1c5b783a77c4a485372d3afe6895b`). PR #30 merged as `279c24d72a64d8a135fa60ef20bdaf99d36816a9`.

## Distribution

- Used `scripts/release.sh 1.5.5 --build-number=12` for the archive, normal Xcode Developer ID export, notarization and styled installer verification.
- Published through `scripts/publish.sh 1.5.5 --reuse-exported-app --build-number=12`; no application source changes between archive and publication. The inspected first installer was preserved separately before the publish workflow rebuilt its installer.
- Both packaging runs used DropDMG profile `dotviewer`. The downloaded public installer was visually checked: purple background, dotted arrow, app left and Applications right. No plain fallback was used.
- Public DMG SHA-256: `d13a0b5e04c33943d8ebf951ff57cb6189a0207d6817c7b0b2ee8ff88b08c3ad`. Matches the local DMG, GitHub asset digest, and Homebrew cask.
- Downloaded public app passes strict signing verification for all architectures, provisioning validation for all six bundles, and Gatekeeper. Public DMG passes stapler validation and Gatekeeper.
- Installed the app from the downloaded public DMG in `/Applications/dotViewer.app` and confirmed version/build 1.5.5 (12), cold launch and ready status.
- Public website `/download` shows 1.5.5; `/download/latest` redirects to the 1.5.5 GitHub DMG. Vercel production commit status succeeded. Homebrew tap contains the matching version and checksum.

## Regression verification

- Final XCTest run: 231 tests, zero failures. Includes Gnuplot grammar tokens/options/Unicode, ambiguous `.gp`, explicit overrides, existing GAP/Godot resolution and status-process tests.
- Python: 20 tests passed, including distribution-profile mismatch rejection and mandatory DropDMG packaging behavior.
- UTI coverage checker: 716/716, no uncovered declared extensions. This is metadata coverage, not a claim that every competing provider is overridden.
- Release Quick Look smoke: Gnuplot, GAP `.gd`, Godot `.gd`, GPX passed. Earlier JSON smoke also passed.
- Finder ordinary Space visually renders Gnuplot with colored commands, options, functions and strings.
- Status refresh and conflict rescan both finish in the release build.
- x86_64 executable launches through Rosetta and reaches ready status; native arm64 launch passes. Host is macOS 26.4.1. This does not replace testing on physical Intel/macOS 15.

## Signing evidence and limits

The untouched public 1.5.4 DMG matches the reporter's checksum and Intel executable UUID. It is Developer ID signed, but has no provisioning profiles despite retaining app-identity and app-group entitlements. The untouched 1.5.3 app has matching profiles and passes the new check; 1.5.4 is rejected for missing profiles. The repaired recovery signer was separately exercised on a development bundle and passed provisioning validation.

The normal Xcode export succeeded for 1.5.5; manual export recovery was not needed for the published app. No profile removal workaround was used.

Godot's upstream macOS app declares `.gd` as `public.gd`; both dotViewer extensions now accept that identifier without exporting or replacing Godot's type. Confirmation of the reporter's exact `.gd` associations remains pending.

Follow-up release links posted on issues #24, #28 and #29. Reporter confirmation on Intel/macOS 15 remains pending; no claim of reproducing that physical environment was made.
